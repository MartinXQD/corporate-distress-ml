# Acknowledgements

This repository presents an independent extension of an earlier UCLA MFE 413 team project. The original course submission is not represented as a sole-authored work.

The original report, dated May 23, 2026, credits Gus Guenther; Zhixiang (Eason) Chen; Yingqi Fang; Qidian (Martin) Xing; Yiyang (Faye) Xie; Xiaoyue Wang; and Xianghan Zhu. They are acknowledged for the original team project, not listed as coauthors of this independent extension. The original report, private communications, assignment materials and teacher feedback remain local.

The extension uses standard algorithms implemented with scikit-learn, XGBoost, CatBoost, imbalanced-learn and PyTorch. The compact FT-Transformer is an independent educational implementation inspired by Gorishniy et al. (2021), not a claim to reproduce their complete benchmark or invent feature tokenization, residual networks or attention. See `docs/REFERENCES.md` for original sources.

Candidate data source: sowide/bankruptcy_dataset. Please cite the upstream data papers and observe applicable acquisition terms. The public repository intentionally excludes all source and processed datasets.
